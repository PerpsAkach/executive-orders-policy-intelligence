# Historical source boundary

The original internal project was known as **SUBCOMMITTEE**.

Three complete denerated historical classifier versions were recovered from the original project history. Their source hashes are recorded in `docs/PROVENANCE.md`.

They are not committed verbatim here because the originals contain private work-specific filesystem paths. The canonical recovered copies remain in the private recovery archive.

The public implementation under `src/` is explicitly a sanitized/enhanced derivative, not a byte-for-byte historical copy.
